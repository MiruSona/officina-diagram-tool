# 그림 그리기

문서에 그림이 필요하면 글로 풀지 말고 이 툴을 쓴다.
**도면을 넣었으면 검사를 돌리고 오류 0 을 확인한 뒤에 보고한다.** 확인 안 했으면 안 했다고 쓴다.

## 어디서 부르나

앞에 붙는 경로가 다르다. 지금 어디에 있는지 보고 고른다.

| 어디서 쓰나 | 명령 앞자리 |
| --- | --- |
| 스튜디오(서브모듈로 물린 상태) | `node DiagramTool/src/…` |
| DiagramTool 저장소 단독 | `node src/…` |

아래 표는 **단독 저장소 기준**으로 적는다. 스튜디오에서는 앞에 `DiagramTool/` 을 붙인다.

## 무엇을 어떤 코드펜스로

| 그리려는 것 | 코드펜스 | 검사 명령 |
| --- | --- | --- |
| 레벨·맵 | `tilemap` | `node src/tilemap.js <파일>` |
| 프레임·페이싱·개수 분포 | `timeline` `pacing` `count` | `node src/timeline.js <파일>` |
| 생산 사슬·카드·테크 | `chain` `cards` `tech` | `node src/lint.js <파일>` |
| 상태도·흐름도 | `mermaid` | 도구 없음. 아래 규칙만 지킨다 |

- 폴더를 주면 통째로 훑는다 : `node src/all.js Docs`
- 가이드 문서의 **예시 조각은 머리말에 `예시=참`** 을 붙여 건너뛴다.
- `Test/` 는 일부러 틀린 견본이 있으니 넣지 않는다.

## Mermaid 규칙 넷

1. **`-beta` 붙은 종류를 쓰지 않는다.** GitHub 의 Mermaid 버전이 뒤처진다.
2. **노드가 25개를 넘으면 쪼갠다.**
3. **라벨은 항상 큰따옴표로 감싼다.** 괄호·따옴표가 들어가면 파서가 깨진다.
4. **한국어 라벨을 쓴다.** 다만 **터미널에서는 안 보인다** — GitHub 웹이나 VS Code 미리보기로 확인한다.

## 그리지 않는 것

| 무엇 | 왜 |
| --- | --- |
| 아스키 박스 그림 | LLM 이 못 그린다. 타일맵만 예외 |
| 시스템 아키텍처도 | 코드를 본다. 문서로 두면 금방 거짓말이 된다 |
| 난이도 곡선 · 점프 아크 · 정밀 히트박스 | 그림 대신 **표나 파라미터**로 적는다 |

기호·서식 상세는 `Docs/Guide/{타일기호,도면서식,그림그리기}.md`.
장르별 도면 프로필은 `src/profiles.json`.
