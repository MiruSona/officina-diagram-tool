# 견본 — 중력+점프 구간 (검사 4a)

```
node Tools/Draw/tilemap.js Tools/Draw/견본-중력.md --preview
```

## 이동 기준선

```baseline move=gravity name="주인공"
| 항목 | 값 | 비고 |
|---|---|---|
| 점프 최고 높이 | 4 | h (타일) |
| 점프 최대 거리 | 5 | 달리기 상태 (타일) |
| 정점까지 거리 | 2.5 | x_h (타일) |
| 수평 속도 | 8 | v_x (타일/초) |
| 낙하 최대 안전 높이 | 6 | |
```

## 1-1 첫 구간

```tilemap name="1-1 첫 구간" tile=16 move=gravity baseline="주인공"
........................
..........C.............
........####............
........................
..P.....................
#####...................
................C.......

########################
```
범례: P=시작 #=지형 .=허공 C=수집물

- 왼쪽 단 위(4행)에서 뛰어 **3칸 위 발판**에 오른다. 점프 높이 4 안이다.
- 오른쪽으로 더 가면 바닥으로 떨어져 아래 길로 이어진다.
