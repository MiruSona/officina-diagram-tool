# 견본 — 크리티컬 패스 (검사 10)

바닥 위에 `1`~`9` 를 찍어 **지나갈 차례**를 적은 도면이다. `P` 가 0번이다.
**오류 0개가 나와야 한다.** 잡는 것보다 안 잡아야 할 것을 안 잡는 게 어렵다.

```
node DiagramTool/src/tilemap.js DiagramTool/Test/견본-크리티컬패스.md --preview
```

## 1. 방 셋 — 열쇠로 문을 열며 나아간다

방마다 비트가 하나씩 있고, 다음 방으로 넘어가는 문의 열쇠는 **그 앞 방**에 있다.
번호 순서와 열쇠 순서가 맞아떨어져서 검사 10 이 조용해야 한다.

```tilemap name="크리티컬 패스 정상" tile=16 profile="던전"
#########################
#.......#.......#.......#
#..P.1..+..2....+...3...#
#..K....#..K....#...X...#
#.......#.......#.......#
#########################
```
범례: P=시작 #=벽 .=바닥 +=문 K=열쇠 X=출구 1=비트 2=비트 3=비트

| 비트 | 어디 | 무엇 |
| --- | --- | --- |
| 0 (`P`) | 왼쪽 방 | 시작 |
| 1 | 왼쪽 방 | 첫 열쇠를 줍는 자리 |
| 2 | 가운데 방 | 첫 문을 열고 들어와 둘째 열쇠를 줍는다 |
| 3 | 오른쪽 방 | 둘째 문을 열고 들어와 출구 `X` 로 나간다 |

## 2. 비트가 없는 도면 — 검사 10 이 조용히 넘어간다

대부분의 도면은 비트를 안 찍는다. **없다고 알리면 시끄럽기만 하다.**

```tilemap name="비트 없음" profile="던전"
###########
#..P..#...#
#..K..+...#
#.....#..X#
###########
```
범례: P=시작 #=벽 .=바닥 +=문 K=열쇠 X=출구
