# 견본 — 던전 1층 첫 구간

기본 프로필(쿼터뷰 · 4방향 · **평면**) 으로 실제 레벨 한 구간을 그려 본 것이다.
**잠금-열쇠 순서**가 들어 있다 — 첫 열쇠로 첫 문을 열고, 그 안의 둘째 열쇠로 출구 쪽 문을 연다.

```
node DiagramTool/src/tilemap.js DiagramTool/Test/견본.md --preview --html DiagramTool/Test/견본.html
```

## 구간 설계 메모

| 방 | 무엇 |
| --- | --- |
| 왼쪽 위 (시작) | 시작점 · 수집물 1 · **열쇠 1** |
| 왼쪽 아래 | 적 1 · 체크포인트. 막다른 곳이라 안 가도 된다 |
| 가운데 | 적 1 · **열쇠 2**. 아래로 좁은 통로 하나 |
| 오른쪽 | 적 1 · 수집물 1 · **출구** |
